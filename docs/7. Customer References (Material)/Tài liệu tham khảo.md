# Tài liệu tham khảo API Tích hợp (Integration API Documentation)

Dưới đây là danh sách các tài liệu tham khảo chính thức cho các dịch vụ API được tích hợp trong hệ thống SeShop:

## 1. Cổng thanh toán (Payment Gateway)
* **Stripe API Documentation**: [https://docs.stripe.com/api](https://docs.stripe.com/api)
  * *Mục đích*: Tích hợp thanh toán trực tuyến, quản lý giao dịch thẻ tín dụng/thẻ ghi nợ, xử lý hoàn tiền (Refunds) và webhook cập nhật trạng thái thanh toán.

## 2. Dịch vụ Vận chuyển & Giao nhận (Shipping & Logistics)
* **Giao Hàng Nhanh (GHN) API Documentation**: [https://docs.ghn.vn/](https://docs.ghn.vn/)
  * *Mục đích*: Tính toán phí vận chuyển (Shipping Fee), dự kiến thời gian giao hàng (Lead Time) và quản lý vận đơn giao nhận.

## 3. Tích hợp Mạng xã hội & Marketing (Social Media & Marketing)
* **Instagram Platform / Meta Graph API**: [https://developers.facebook.com/docs/instagram-platform](https://developers.facebook.com/docs/instagram-platform)
  * *Mục đích*: Tích hợp tài khoản doanh nghiệp Instagram, tự động hóa đăng bài (Compose & Publish), quản lý bản nháp (Drafts) và đồng bộ hóa dữ liệu tương tác.
